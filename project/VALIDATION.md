| 检查 | 结果 |
| --- | --- |
| 7 组纯 Java 回归 | 通过：App 3 组、Bridge 4 组 |

| 两个模块的 Java 编译 | 使用 JDK 21 与已有 API 34 编译类库通过 |

| 系统默认 HOME、固件启动路由、待机唤醒 | 未执行，不作保证 |

编译输出出现 Java 8 source/target 兼容选项及旧 Android API 的弃用提示，没有编译错误。离线独立编译的临时文件已清除；本包只保留源代码、配置、文档和验证脚本。

纯 Java 测试包括：App/Bridge 两份按键测试各 46 项检查、Bridge 前台转交 15 项断言、冷启动及首次焦点截止 15 项检查、开机入场策略 12 项用例，以及入场生命周期和 80 种应用数量下的分页边界测试。首次焦点截止检查由实际启动入口调用，包含精确到期与超时回调尚未派发的晚到焦点。

这些结果证明当前资源、Java 源码和 DEX 转换可以通过已有本地工具编译，不等于标准 Gradle 打包已完成，也不等于在另一台电视上完成适配。
